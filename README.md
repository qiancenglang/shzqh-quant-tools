欢迎来到 **数智量化 (shzqh.cn)** 的 GitHub 官方仓库。

本仓库主要用于记录和分享我们在**国内期货市场（商品期货/金融期货）**的量化研究工具、策略模型与数据接口。

## 🚀 核心功能

我们的线上系统 (https://shzqh.cn) 目前提供以下核心量化服务：

*   **全品种量化扫描**：每日对 30+ 期货品种进行多因子扫描，输出融合分、多空方向、置信度排名。
*   **行动地图**：结合资金动向、技术形态与基本面底牌，提供每日最强信号关注池。
*   **结构位测算**：基于 ATR 与布林带等指标，自动测算精准的支撑位、压力位及结构失效位。
*   **策略简报历史**：所有品种的历次研判记录存档，方便复盘与胜率追踪。
